# Symptom Intake App - Frontend

## Local Setup

Run all the commands in /frontend directory.

Firstly, you need to copy and set environmental variables to your .env file:
```bash
cp frontend/.env.example frontend/.env
```

Install the dependencies:
```sh
npm install
```

### Compile and Hot-Reload for Development

```sh
npm run dev
```

### Compile and Minify for Production

```sh
npm run build
```
